New tools get a weekend. The ones that last are the ones that replace a note on a phone, not the ones that add a fifth login.

In this example week, creators kept a queue that posted when they were offline and a caption box that did not eat line breaks. They dropped the analytics overlay that charted feelings.

## The test
If you did not open it on day six, it is not a tool. It was a launch.
