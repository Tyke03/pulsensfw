A score is a viewer's score. It says whether we would open it again.

Picture, comfort, noise, and whether we would open it again get equal weight unless the category says otherwise. A toy can be powerful and still lose points for noise. A site can have a huge library and still lose points if the player is a trap.

Citations, when publishing starts, sit next to the claim. On this shell the numbers are examples so the score box has a job.
