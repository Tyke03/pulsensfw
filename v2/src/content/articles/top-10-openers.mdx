The worst opener is a paragraph of rules. The best one is a situation.

1. Name the time of day.
2. Name one object in the room.
3. Ask for a disagreement, not a compliment.
4. Keep the boundary in a separate card, not in the flirtation.

The other six are variations. If the reply sounds like a help desk, delete the opener and start from the object in the room.
